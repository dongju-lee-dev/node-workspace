# node-workspace-webui: signal

1. 구현: 비동기로 node의 코드가 contnet의 node id를 이용하여 코드를 실행
   1. 코드 실행
   2. 노드의 콘텐츠 코드 실행
   3. 노드의 콘텐츠 코드에서 실행 호출

2. 구현 UI: 시그널 노드를 사용할 수 있도록 노드를 지정하는 기능
   1. 시그널 노드를 선택한다.
   2. signal link를 클릭한다.
   3. workspaceTop에 취소 버튼이 활성화 된다.
   4. 실행을 원하는 노드에 가서 signal link를 다시 한 번 누르면 연결된다.
   5. 4번과 동일하게 signal 사이드 패널에서 확인, 작업 할 수 있다. 

3. 구현 UI: 시그널 노드를 연결되어 있는 노드 해제 방법
   1. 시그널 노드를 선택한다.
   2. signal unlink를 클릭한다.
   3. 해제 끝

4. 간편 실행 기능
   1. 노드를 선택 후 easy starter register를 클릭한다.
   2. signal의 사이드 패널에서 등록된 것을 보여준다.
   3. signal의 사이드 패널에서 등록된 것을 실행, 해제할 수 있다.
